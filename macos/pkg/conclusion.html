Ready to print

If your printer was switched on and connected, it now appears in System Settings → Printers & Scanners as Samsung … using the (SpliX) driver. Just print from any app.

If it is not there yet:

  1. Connect or switch on the printer.
  2. Open System Settings → Printers & Scanners → Add Printer…, select it, and under Use choose Select Software…, then type SpliX and pick your model.

Toner level is not available on these printers (the engine does not report it). Help, model list and source code: github.com/boredjar-com/splix-macos. Free software, GPL-2.0.
